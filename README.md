# Hausarztzentrum Wetzel – Self-Check-In Ankündigungs-PWA

Eine bewusst **einseitige iPad-PWA** für den Empfang.

Die Seite kündigt ausschließlich an, dass der Patienten Self-Check-In **in Kürze verfügbar sein wird**. Es gibt noch keinen Start-Button und keine Eingabe von Patientendaten.

## GitHub Pages

Alle Dateien ins Repository laden und unter **Settings → Pages** über den Branch `main` und den Ordner `/ (root)` veröffentlichen.

Danach die GitHub-Pages-Adresse auf dem iPad in Safari öffnen und über **Teilen → Zum Home-Bildschirm** als App hinzufügen.
